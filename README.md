# אתר דניאלה הדר

אתר Next.js (App Router) + TypeScript + Tailwind CSS, בעברית מלאה ו-RTL. מחליף בהמשך את אב-הטיפוס הסטטי בתיקיית `daniella-hadar-landing`.

## הרצה מקומית

```bash
npm install
npm run dev
```

## מצב נוכחי (Milestone 1)

- כל העמודים מהתוכנית בנויים: בית, קורסים + עמוד קורס, מרכז ידע + מאמר, אודות, המלצות, יצירת קשר, הצהרת נגישות, מדיניות פרטיות.
- תוכן זמני בקובץ `src/lib/content.ts` — מסומן `DRAFT` במקומות שטעונים אימות מול דניאלה.
- אין עדיין חיבור ל-CMS (Sanity) — מתוכנן ל-Milestone 2.
- טופס יצירת הקשר אינו שולח נתונים בפועל עדיין — מחובר לרב-מסר רק ב-Milestone 3.
- קישורי רכישת קורסים עדיין לא מוצגים בפועל, עד אימות כתובות Schooler/Cardcom מול דניאלה.
