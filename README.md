# אתר דניאלה הדר

אתר Next.js (App Router) + TypeScript + Tailwind CSS, בעברית מלאה ו-RTL. מחליף בהמשך את אב-הטיפוס הסטטי בתיקיית `daniella-hadar-landing`.

## הרצה מקומית

```bash
npm install
npm run dev
```

## מצב נוכחי

- האתר כולל את עמודי הבית, קורסים, מרכז הידע, אודות, יצירת קשר, המלצות, פרטיות ונגישות.
- התוכן מנוהל באמצעות Sanity, עם תוכן fallback מקומי שמסומן `DRAFT` במקומות שטעונים אימות מול דניאלה.
- מסלול הפנייה הפעיל הוא טלפון או מייל. אין באתר טופס ששולח מידע.
- נוסחי כפתורי הפעולה הם נוסחי עבודה וממתינים לאישור דניאלה לפני פרסום.
- תשתית רשימת התפוצה כבויה כברירת מחדל. `NEWSLETTER_MODE=preview` מציג טופס מושבת לבדיקה מקומית בלבד; הוא אינו שומר או שולח מידע.
- קישורי רכישת קורסים מוצגים רק לאחר אימות כתובת רכישה רשמית.
- מדיניות הפרטיות והצהרת הנגישות נשארות `noindex` עד לאישור נוסחים סופיים.
