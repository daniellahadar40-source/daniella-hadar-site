# מדריך פרסום קצר ב-Sanity

## סדר העבודה המומלץ

1. יוצרים או פותחים פריט תוכן.
2. משאירים את הסטטוס “טיוטה” בזמן הכתיבה.
3. משלימים את כל השדות ואת הטקסט החלופי לתמונות.
4. בודקים שאין מידע אישי או רפואי שאינו מיועד לפרסום.
5. משנים ל“פורסם” רק לאחר אישור התוכן.
6. שומרים ומוודאים שהתוכן נראה נכון באתר.

## כללי בטיחות לתוכן

- אין לפרסם המלצה בלי סימון “אישור פרסום”.
- אין לפרסם מחיר, הכשרה או ניסיון שלא אומתו.
- מאמר מקצועי צריך לכלול מקורות ותאריך עדכון.
- אין להעלות מסמכים רפואיים או פרטים מזהים ל-Sanity.
- קורס שאינו מוכן נשאר “טיוטה”, “בקרוב” או “לא מוצג”.
- אם יש ספק, משאירים טיוטה ולא מפרסמים.

## אזורי הניהול

- **הגדרות אתר:** שם, תמונות, פרטי קשר וקישורים.
- **שירותים:** מסלולי הליווי שמוצגים בעמוד הבית.
- **קורסים:** תיאור, שיעורים, מחיר וקישור רכישה.
- **מאמרים וקטגוריות:** מרכז הידע והמקורות.
- **המלצות:** רק המלצות אמיתיות עם אישור.
- **שאלות נפוצות:** תשובות כלליות שמופיעות באתר ועשויות לסייע לעוזר הניווט.
- **עוזר הניווט:** הודעת פתיחה, גבולות ושאלות מוצעות.
